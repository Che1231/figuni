# FIGUNI 피규니

**一张照片，AI 生成专属白模，到 DIY 店亲手上色。**
사진 한 장으로 AI가 나만의 화이트 피규어를 만들고, DIY 공방에서 직접 칠합니다.

FIGUNI = Figurine + Unique

- 官网 / 홈페이지：https://www.figuni-ai.com
- 流程演示 / 데모：https://www.figuni-ai.com/demo/

## 这是什么

FIGUNI 用 AI 把宠物或原创角色的照片设计成专属白模（未上色手办），由合作工厂打印后，连同专属配色卡寄到附近的 DIY 店，顾客照着编号亲手上色。平台不开工厂、不开门店，只负责设计和对接。

这个仓库是 FIGUNI 的官网和小程序流程演示，都是纯静态页面：

- **官网（`/`）**：首页的 3D 白模可以点四种颜色"上色"，涂满后显示完整效果；下面是四步流程、与其他选择的对比、需求调研数据、门店与工厂合作方式和团队介绍。
- **演示（`/demo/`）**：手机小程序的完整下单流程（上传照片 → 选效果图 → 转动 3D 模型 → 选方案 → 确认订单）和社区页。点模型上的部位会高亮并告诉你该涂哪种颜色。

演示中的 AI 步骤使用团队成员家柴犬"豆豆"的实测结果代替，不调用真实接口；社区帖子、门店和订单均为示例内容。页面默认韩语，可切换中文。

## 目录

```
index.html          官网
assets/             官网图片（白模海报、演示截图、分享图）
demo/index.html     流程演示
demo/assets/        演示素材：照片、效果图、3D 模型（GLB，base64）、部位分区数据
vercel.json         部署配置（目录地址自动补斜杠）
```

## 技术

- HTML / CSS / 原生 JavaScript，无构建步骤
- 3D：three.js 0.160（jsDelivr 加载），GLTFLoader 解析 base64 形式的 GLB；按面片的部位编号实现点选高亮和分色上色
- 字体：Google Fonts（Fredoka、Noto Sans SC / KR）
- 部署：Vercel 静态托管，域名解析在 Cloudflare

## 本地运行

在仓库根目录启动任意静态服务器，然后打开 http://localhost:8000 ：

```bash
python -m http.server 8000
```

页面使用以 `/` 开头的绝对路径，请从仓库根目录启动服务器，不要直接双击打开 HTML 文件。

### 한국어 요약

FIGUNI는 반려동물이나 캐릭터 사진을 AI로 맞춤 화이트 모델로 디자인하고, 제휴 공장에서 출력해 전용 컬러 카드와 함께 가까운 DIY 공방으로 보냅니다. 고객은 번호대로 직접 칠해 나만의 피규어를 완성합니다.

이 저장소에는 FIGUNI 홈페이지(`/`)와 미니프로그램 흐름 데모(`/demo/`)가 들어 있습니다. 데모의 AI 단계는 팀원의 시바견 ‘두두’로 직접 만든 결과로 대신하며, 실제 API는 호출하지 않습니다.
